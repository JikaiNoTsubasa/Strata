- **Date** : 16/11/2026, même machine que J0.
- **Comparaison équitable** : le code J0 a été remesuré le même jour, dans le même environnement. L'environnement de bureau a changé depuis la mesure J0 : le code J0 lui-même mesure désormais 77,8 Mo en session au lieu de 62,9 Mo.

## Constats

- **Icône** : lorsqu'une icône d'application SVG en couleur est affichée, GTK la décode via glycin, dans un sous-processus isolé par `bwrap`, pour environ 5 à 8 Mo. Des rendus PNG (`data/icons/hicolor/<taille>/apps/`) sont désormais fournis : GTK les décode avec son chargeur intégré.
- **Binaire** : il passe de 1,6 à 8 Mo (TLS, PostgreSQL, SQLite, D-Bus pour le trousseau). Environ 4 Mo de PSS sont des pages de code adossées au fichier (`Private_Clean`), que le noyau peut récupérer sous pression mémoire. `opt-level="s"` ferait gagner environ 1 Mo, sans effet sur le démarrage ; à réévaluer en J3 avec les mesures de défilement (ADR-0011).
- Le trousseau n'est contacté qu'à l'ouverture du dialogue de connexion, ce qui évite le coût de D-Bus/zbus au démarrage.
