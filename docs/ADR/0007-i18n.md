# ADR-0007 — i18n : gettext (`gettext-rs`)

**Statut** : Proposé

## Décision
- **gettext** via `gettext-rs` avec la feature `gettext-system` (utilise la libintl de la glibc, pas de recompilation de gettext).
- Raison principale : les fichiers `.ui` GtkBuilder (`translatable="yes"`), le `.desktop` et l'AppStream se traduisent nativement avec gettext/`xgettext`/`msgfmt` ; un seul système pour tout.
- Langue source anglaise ; `po/fr.po` ; `po/POTFILES.in` ; extraction via `cargo xtask i18n` (`xgettext --keyword=gettext --keyword=pgettext:1c,2 --keyword=ngettext:1,2`).
- Pluriels via `ngettext` ; formats de nombres/dates d'affichage via `glib::DateTime::format` (locale) ; jamais pour l'export.
- Test CI : `msgfmt --check` et vérification qu'aucune chaîne `.ui` n'est non traduisible (lint simple).

## Alternatives
- **Fluent** : meilleure grammaire, mais ne couvre pas les `.ui`, `.desktop` ni AppStream → deux systèmes. Écarté.
